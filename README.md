 🌱 NaviKalpana – Smart Waste Material Reuse Platform

 📌 About the Project
NaviKalpana is a Smart Waste Material Reuse Platform that helps users convert waste materials into creative and useful products. It provides reuse ideas based on selected materials, budget, and purpose.

🎯 Objectives
- Promote waste management and recycling.
- Encourage creative reuse of waste materials.
- Provide budget-friendly DIY ideas.
- Support sustainable living.

 ✨ Features
- User Registration and Login
- Material-Based Search
- Budget-Based Search
- Purpose-Based Search
- Smart Multi-Material Reuse Recommendations
- Add and View Favorite Ideas

 🛠️ Technologies Used

**Frontend**
- React.js
- HTML
- CSS
- JavaScript

**Backend**
- Java
- Spring Boot
- Spring JDBC (JdbcTemplate)

**Database**
- MySQL

**Tools**
- VS Code
- Postman
- Git & GitHub

🗄️ Database Tables
- users
- materials
- ideas
- favorites
- idea_materials

 ⚙️ How to Run the Project

 Backend
1. Open the backend folder.
2. Configure MySQL database connection.
3. Run the Spring Boot application.

 Frontend
1. Open the frontend folder.
2. Install dependencies:

npm install


3. Start the React application:


npm run dev


4. Open `http://localhost:5173` in your browser.
